# SOCIAL MEDIA & STUDENT WELL-BEING

## Student Social Media Addiction Analysis

### Understanding Digital Habits | Mental Health | Academic Performance

## Project Overview
This project focuses on analyzing students' social media usage patterns and exploring their relationship with student well-being, mental health, and academic performance.

The objective is to understand digital habits and identify patterns that may be associated with social media addiction and its potential impact on students' daily lives.

## Project Objectives
- Analyze students' social media usage habits.
- Explore patterns related to social media addiction.
- Understand the relationship between digital habits and mental well-being.
- Examine the association between social media usage and academic performance.
- Present meaningful insights through interactive data visualizations.

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- Dashboard Development

## Key Focus Areas
- Social Media Usage
- Student Digital Habits
- Mental Health
- Academic Performance
- Student Well-Being

## Project Outcome
The project aims to transform student-related data into meaningful visual insights to better understand digital behavior and student well-being.
